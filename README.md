# EduFlex Pathways

A student-focused education discovery platform for exploring academic programs, tracking interests, and navigating future learning opportunities.

## Overview

EduFlex Pathways is designed to help learners discover programs that fit their interests, strengths, and goals. The product focuses on making education planning simpler through a clean, student-first experience, personalized pathways, and a clear interface for browsing opportunities.

## What I built

- Program and pathway discovery experience
- Student dashboard for saved interests and academic exploration
- Profile and personalization flow
- Bookmarks and referral-style discovery experience
- Responsive UI for desktop and mobile

## Tech stack

- TypeScript
- React
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase

## Features

- Explore educational opportunities by program and interest
- Save relevant courses or pathways
- View personalized learner-facing experiences
- Access a clean and responsive interface
- Build on a structured frontend and database-ready architecture

## Getting started

### Prerequisites

- Node.js 18+
- npm or pnpm
- A Supabase project

### Installation

```bash
git clone https://github.com/jasonntiri1-create/eduflex-pathways.git
cd eduflex-pathways
npm install
cp .env.example .env
npm run dev
```

### Environment variables

Create a `.env` file based on the template below:

```env
VITE_SUPABASE_URL="https://your-project.supabase.co"
VITE_SUPABASE_PUBLISHABLE_KEY="your-supabase-anon-key"
VITE_SUPABASE_PROJECT_ID="your-project-id"
```
